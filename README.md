# Cybersecurity Capstone Project

This repository brings together three cybersecurity projects I worked on as part of my capstone. Each project focuses on a different area of cybersecurity, from security automation and machine learning to network vulnerability assessment and secure API development.

The goal was to gain hands-on experience with security tools, explore common vulnerabilities, and apply security best practices in practical projects.

## Projects

### 1. Python Security Automation & ML

🔗 **Repository:** [python-security-automation-ml](https://github.com/4aru5h/python-security-automation-ml)

A Python project focused on automating security tasks and exploring how machine learning can help detect suspicious activity.

**What it includes:**
- A multithreaded TCP port scanner with banner grabbing
- A security log parser with threat intelligence integration
- VirusTotal API integration
- Random Forest and Isolation Forest models for threat detection and anomaly detection

**Technologies:** Python, Scikit-learn, VirusTotal API

---

### 2. Network Reconnaissance & Vulnerability Assessment

🔗 **Repository:** [network-recon-vuln-assessment](https://github.com/4aru5h/network-recon-vuln-assessment)

This project focuses on network reconnaissance and identifying potential security weaknesses in a controlled lab environment.

**What it includes:**
- Host discovery and passive OSINT
- TCP port scanning and service detection
- OS fingerprinting and DNS enumeration
- Vulnerability scanning using Nessus
- CVE research and remediation recommendations

**Technologies:** Nmap, Nessus, OSINT, DNS

---

### 3. Secure Flask REST API

🔗 **Repository:** [flask-secure-api](https://github.com/4aru5h/flask-secure-api)

A Flask REST API project focused on learning and implementing secure development practices for web applications.

**What it includes:**
- Password hashing
- Protection against SQL injection using parameterized queries
- Environment variables for managing sensitive configuration
- Authentication and authorization controls
- Automated security checks
- STRIDE threat modeling and OWASP Top 10 considerations

**Technologies:** Python, Flask, SQL, GitHub Actions

---

## Technologies Used

- **Programming:** Python
- **Machine Learning:** Scikit-learn
- **Security Tools:** Nmap, Nessus, VirusTotal API
- **Web Development:** Flask, REST APIs, SQL
- **Security Concepts:** Threat Detection, Network Reconnaissance, Vulnerability Assessment, Secure Coding, Threat Modeling

## What I Learned

Through these projects, I gained practical experience with Python security tools, machine learning techniques for threat detection, network scanning, vulnerability assessment, and secure API development. I also learned more about common security risks and ways to reduce them.
